\# 💸 FinPulse AI | Privacy-Preserving Financial Telemetry \& Anomaly Screener



An AI-driven personal finance monitoring and risk telemetry dashboard built with Streamlit, Plotly, and Scikit-Learn.



\## 📌 Features

\- \*\*Zero-Risk Synthetic Banking Engine:\*\* Generates realistic Indian UPI, POS, and NEFT debits without exposing real banking credentials.

\- \*\*Unsupervised Anomaly Screener:\*\* Powered by `IsolationForest` to flag unusual debit spikes and potential money leaks.

\- \*\*Live Spending Telemetry:\*\* Interactive cash-flow trajectory, monthly velocity charts, and domain breakdown.

\- \*\*Real-Time Simulation Sandbox:\*\* Test hypothetical transaction amounts against learned Gaussian distribution thresholds.
